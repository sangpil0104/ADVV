# 실행 검증 범위

확인일: 2026-09-30. 아래 수치는 개발 서버의 완료된 `runs/first_trial_001/report.json` 및 후보 record에서 확인했다. 원본·생성 이미지, 실행 폴더와 로컬 인증·모델 파일은 Git 저장소에 포함하지 않는다.

## 실제 모델 연결

고양이 원본 한 장(528×598 px)을 입력해 무작위 rotation 계획을 만들고 실제 DragFlow와 로컬 Qwen3.5-4B를 실행했다. 이는 연결 확인용 사례이며 산업 결함·사고·희귀 생물 데이터에 대한 품질 평가가 아니다.

| 항목 | 결과 |
| --- | --- |
| backend | `dragflow+qwen_local` |
| run / 최종 상태 | `first_trial_001` / `completed` |
| 목표 / 고유 채택 / 생성 시도 | 1 / 1 / 1 |
| 물리 / 의미 VQA | YES / YES |
| 원본 의미 추정 | 12.65초 |
| 후보 생성 | 592.06초 |
| 물리 / 의미 검증 | 11.09초 / 2.02초 |
| 생성 / 검증의 관측 GPU 메모리 피크 | 약 18.1 / 8.8 GiB |

시간은 각 단계의 관측값이며 정상 상태의 반복 처리량을 보장하지 않는다. 메모리는 단일 논리 장치의 최대 allocated VRAM으로, 여러 GPU의 합계나 시스템 전체 메모리가 아니다. 당시 생성에는 GPU 0·1, Qwen에는 GPU 0을 순차 사용했다. seed·실제 적용 좌표·영역·두 판정·채택 파일·시각화·export가 저장되었다.

## CPU 검증

2026-09-30 `python -m pytest -q`에서 **79개 통과**. 엄격한 응답 파싱, AND 판정, 목표 수량, 중복, NO 정리, 중단·재개, 원본 profile 보류, 좌표와 시각화 복구 및 CLI 수량 입력을 포함한다. 이 분기 검사는 가중치 없이 fixture로 실행하며 실제 생성 성능 평가와 구분한다.
